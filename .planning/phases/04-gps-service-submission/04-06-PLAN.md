## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-20 | Information Disclosure | pending pins leak | mitigate | Separate authed-only query (enabled: !!session) backed by auth.uid()-scoped RPC; Phase 3 search RPCs untouched; no client-side "my rows" filter. |
| T-04-21 | Tampering | withdraw others' pins | mitigate | withdrawSubmission is server-scoped (04-01); UI only offers withdraw on the submitter's own pending sheet. |
| T-04-22 | Tampering | instant malicious code overwrite | mitigate | UI stages the code and shows pending-confirmation only; server requires a different user's confirm (04-02, D-24). |
| T-04-23 | Information Disclosure | code shown to anon | mitigate | Update-code action and any code display are signed-in-only; anon routed to AuthRequiredModal; public detail RPC never returns the code. |
