## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → register_device_token | Owner-scoped token write; owner derived server-side, never a client param |
| Edge Function → Expo Push API | Server-only egress; database secret keys come from function environment, while Vault protects only the scheduled invocation URL/custom secret |
| worker → notification_outbox | Concurrent/crashing workers claim under a lease; settlement is compare-and-set so a reclaimed row is never clobbered |
| package installs | npm supply-chain surface for expo-notifications/expo-device |
