# Quick Task 260704-0kt: Harness Integrity Fix Batch

## Origin

2026-07-04 harness audit (session following the 2026-07-03 full project audit). Five verified findings in the Claude/Antigravity/Codex integration machinery. Finding numbers below match the audit report delivered in-session.

## Tasks

### T1 — Normalize review-queue paths in the PostToolUse hook (Finding 1, significant)

**File:** `.claude/settings.json`
**Problem:** The hook appends the raw `tool_input.file_path` — an absolute Windows backslash path (verified empirically by piping simulated hook JSON through the exact script). `check-review-artifacts.js` compares queue entries against `git diff --cached --name-only` output (repo-relative, forward slashes). Absolute entries never match, so the pre-commit review-artifact gate silently no-ops. The gate has only been working because past sessions hand-normalized the queue.
**Fix:** In the hook, relativize the path against the project root (hook CWD is the project root), convert backslashes to forward slashes, and only queue files that live under the project root (out-of-repo files are not reviewable by this project's gate and should never enter the queue).
**Verify:** Pipe simulated PostToolUse JSON (absolute in-repo path, absolute out-of-repo path, duplicate path) through the new script → expect exactly one repo-relative forward-slash entry.

### T2 — Replace the broken full-packet Antigravity invocation with the packet-file pattern (Finding 2, significant)

**Files:** `.claude/commands/antigravity-review.md`, `AGENTS_ROSTER.md`, `AGENTS.md`
**Problem:** All three document `antigravity -p "<entire multi-document packet>"`. Windows' ~32K command-line limit makes this fail silently ("filename or extension too long") for any real packet — established during WU-02-T5. The working pattern (short prompt directing Antigravity, an agentic CLI with file access, to read the packet from disk) exists only in session memory, not the repo. `AGENTS.md` additionally wraps PowerShell `Get-Content` in a `bash` code fence.
**Fix:** Keep the packet-building logic in `/antigravity-review` unchanged (the packet still goes to `.claude/antigravity-prompt-latest.md` — the commit hook checks it). Change only the invocation: a short prompt telling Antigravity to read the packet file, inspect the named files from disk, and return the verdict; stdout captured to `.claude/antigravity-review-latest.md` as before. Document the 32K limit as the reason. Update the manual-invocation snippets in `AGENTS_ROSTER.md` and `AGENTS.md` to the same pattern (and fix the code fence).
**Verify:** New short prompt is well under 8K chars; command doc no longer contains any inline-packet `antigravity -p` form.

### T3 — Fix stale reviewer output formats in AGENTS_ROSTER.md (Finding 3)

**File:** `AGENTS_ROSTER.md`
**Problem:** The 2026-07-02 process change (`c2e1e33`) made "Runtime Boundary Check" a mandatory verdict section, enforced by `.claude/hooks/check-review-artifacts.js`. `ANTIGRAVITY.md`/`CODEX.md` were updated; the roster's two duplicated format blocks were not. A reviewer following the roster (required reading) produces a verdict the commit hook rejects.
**Fix:** Add the missing "Runtime Boundary Check" section to both format blocks, matching the canonical wording, and add a one-line precedence note under each: the canonical format lives in ANTIGRAVITY.md / CODEX.md and wins on any future divergence.
**Verify:** Both roster format blocks contain the section; wording matches the canonical files.

### T4 — Gate the Stop-hook reviewer reminder on a non-empty queue (Finding 4)

**File:** `.claude/settings.json`
**Problem:** The first Stop hook emits "Reviewers needed before committing…" unconditionally on every turn end, even with an empty queue — noise that trains the operator to ignore it.
**Fix:** Emit the systemMessage only when `.claude/review-queue.txt` exists and has at least one non-blank line.
**Verify:** Run the hook script body with an empty queue (no output) and a populated queue (JSON emitted).

### T5 — Fix stale "Phase 1" wording in /review-gate (Finding 5, trivial)

**Verify:** Text updated; no other Phase-1 fossils in the file.
