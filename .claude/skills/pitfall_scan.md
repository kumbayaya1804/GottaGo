# Skill: Pitfall Scan

## Purpose
Proactively detect domain-specific "Traps" before they are committed to code.

## Workflow
1. Before approving an implementation plan, read [.planning/research/PITFALLS.md](file:///C:/Users/mrsai/Gotta%20Go/.planning/research/PITFALLS.md).
2. Map the proposed changes to the "CRITICAL" and "MAJOR" pitfalls listed.
3. Flag any proposed logic that matches a "What goes wrong" scenario.
4. Require the "Prevention" strategy from the pitfall doc to be included in the plan.
