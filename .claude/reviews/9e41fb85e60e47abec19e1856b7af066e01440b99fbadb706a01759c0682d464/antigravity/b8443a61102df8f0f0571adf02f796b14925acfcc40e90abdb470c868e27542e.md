### Adversarial Disproof
- **`core.quotePath` Quoted Filename Evasion**: Tested unqueued protected files with non-ASCII characters (`docs/café.md`) and tab characters (`docs/a\tb.md`). Without `-z`, git quoted them as `"docs/caf\303\251.md"`, slipping past Check B. With `stagedNames` reading raw NUL-separated names, Check B intercepts both and exits 1 with a missing queue entry error.
- **Pathspec Magic Fingerprint Evasion**: Verified that queuing magic names such as `:(exclude)*.txt` or `:(top)x.md` binds deterministically to the staged bytes. Restaging modified content changes the scope_hash, disproving fingerprint stagnation. Restaging unqueued `ab.txt` leaves queued `a*.txt` scope_hash unchanged.
- **Symlink Escape Traversal**: Tested `toRepoRelative` with an in-repo symlink pointing outside the repository (`repo/link -> ../outside`). With resolved containment enforced via `realpathOfExisting`, the traversal is caught and returns `null`.
- **Whitespace / Representation Corruption**: Tested queue entries with leading or trailing whitespace (`spaced.txt `) and newlines (`a\nb.md`). Because trimming would mutate the path into a different filename, `assertRepresentable` disproves silent acceptance and rejects the entry with non-zero exit code 1.
- **Case Sensitivity Collision**: Tested sibling directory differing only by case (`/tmp/REVIEW-ROOT/other.txt` vs `/tmp/review-root`). On case-sensitive environments, `isCaseInsensitiveFs` yields `false` and `stripPrefix` rejects the path (`null`).
- **Pathspec Injection in `stage-queue`**: Tested queue entries containing `*`, `?`, and git pathspec magic `:(glob)*.txt`. With `--literal-pathspecs`, git treats them as literal filenames and refuses to stage unrelated files.
- **Command / Option Injection in `stage-queue`**: Tested queue entry `--weird; echo PWNED`. Passed safely after `--` delimiter without shell interpretation or option parsing.
- **NotebookEdit Evasion**: Tested whether non-standard file edit payloads evade `queue-edit`. Both `file_path` and `notebook_path` are ingested.
- **Hook Stdin Tampering**: Tested invalid non-JSON stdin against `queue-edit` and `stop-review-queue`. Both fail loudly (exit code 1) with descriptive stderr rather than silently bypassing checks.
