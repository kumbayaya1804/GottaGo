### Adversarial Disproof
- **Premise 1**: Iterative percent-decoding in `canonicalizePathText()` could enter an infinite loop on cyclic input.
  - **Counterexample attempted**: Analyzed regex replacement `/%([0-9a-f]{2})/g` with `String.fromCharCode(parseInt(hex, 16))`.
  - **Outcome**: Disproved. Every decoding step replaces a 3-character hex tuple `%XX` with a single character, strictly reducing string length ($N_{t+1} < N_t$), guaranteeing finite termination without an arbitrary loop counter.
- **Premise 2**: `workingTreeBlobOid()` via `git hash-object` allows an unstaged archive to pass.
  - **Counterexample attempted**: Unstaged the archive in test fixture (`git reset -- .claude/reviews`).
  - **Outcome**: Retained. `stagedBlobOid()` returns `null` when the file is unstaged, causing `stagedOid !== null` to fail and correctly blocking pre-commit.
