- `NOTE (follow-up)`: Test flake hazard in `app/src/app/__tests__/(components)/AuthRequiredModal.test.tsx`:
  Lines 78–83 (`uses instant appear (animationType "none") when reduced motion is enabled`) performs:
  ```ts
  const modal = await findByTestId('auth-required-modal');
  expect(modal.props.animationType).toBe('none');
  ```
  without wrapping the assertion in `waitFor`. Because `findByTestId` resolves as soon as the modal mounts with its initial state (`reducedMotion = false`, yielding `animationType="slide"`), if the mocked `isReduceMotionEnabled` resolution does not trigger a React state re-render before `findByTestId` returns, the expectation fails with `Expected: "none", Received: "slide"`. This test is outside the staged queue and passed upon individual and subsequent full runs, but should be hardened with `await waitFor(() => expect(modal.props.animationType).toBe('none'))`.
