### Findings

- **[MAJOR] `.claude/hooks/check-review-artifacts.js:393-451` and `.claude/hooks/check-review-artifacts.test.js:1102-1113` — The new named-reference table omits `&percnt;`, leaving a directly reproducible blind-review bypass.** CommonMark accepts every valid HTML5 named character reference in URLs, and the authoritative HTML5 entity table maps `&percnt;` to `%`. A packet can therefore contain `&percnt;2eclaude/reviews/<scope>/antigravity/x.md`; CommonMark turns the named reference into the already-dangerous `%2e` form, but the staged `canonicalizePathText()` leaves `&percnt;` untouched. Executing the real staged function returned `false` for both the fully encoded and mixed `&percnt;2e` variants while literal and `%2e` variants returned `true`. The 49th test covers decimal, hexadecimal, `period`/`sol`, and `amp`, but not this named-to-percent composition. Required fix: add `percnt: '%'` at minimum, add a real-hook regression test for `&percnt;2e`/`&percnt;2f` and mixed/nested forms, and derive the path-relevant table from the authoritative HTML5 entity set so another path-producing name is not omitted manually. Authorities: [CommonMark entity-reference rules](https://spec.commonmark.org/spec#entity-and-numeric-character-references) and [WHATWG HTML entity table](https://html.spec.whatwg.org/entities.json).

- **[MAJOR] `.claude/hooks/check-review-artifacts.js:115-162, 256-272, 632` — Commit authorization still evaluates mutable working-tree trust inputs instead of the staged bytes being committed.** Policy, calibration contract/evidence, calibration prompts/archives, and canonical packets/verdicts enter enforcement through `fs.readFileSync`/`readFileSafe`. An unstaged weakened policy or substituted receipt can govern acceptance while Git commits different staged bytes. Archive OID comparison does not bind these other trust inputs to the index. Required fix: load commit-gating inputs from the index or fail closed whenever each trust input's clean-filtered working-tree blob differs from its staged blob; add integration coverage that stages restrictive bytes, weakens only the worktree copy, and proves rejection.

- **[MAJOR] `.claude/hooks/check-review-artifacts.js:201-237, 319-340`, `.claude/antigravity-calibration-contract.json:3-13`, and `.claude/hooks/check-review-artifacts.test.js:30-90, 544-565` — Calibration outcome truth remains author-supplied.** The gate trusts `falseApprovals`, ignores rows not labeled `passed: true`, and derives case success from those author-provided booleans. The passing fixture demonstrates that a hand-authored evidence file containing clean `ADVISORY` archives, `passed: true`, and `falseApprovals: 0` restores active authority without a trusted expected outcome proving any canary defect was detected. `passingVerdicts` prevents a contradictory token but cannot establish expected-versus-observed correctness. Required fix: bind each case/run to runner-owned hidden expected outcomes and derive `passed` and false-approval counts from the observed verdict/findings; add tests showing forged header/row values cannot grant authority.

- **[MAJOR] `.beads/context/execution-state.md:6,13,16-17` and `.planning/stale-info-scan-latest.md:31-36,68-72` — Queued active-state artifacts contradict the current index and each other.** Execution state says the types file is “staged, awaiting review” at line 6, “UNSTAGED” with packets “never reviewed” at line 13, and fully reviewed at line 17. It also tells recovery to look for round-5 artifacts under intermediate hash `b8dad72e...`, while the staged index, packet, and `.planning/STATE.md` identify `f2bac4a9...`. The stale-info scan claims self-asserted calibration is fixed and that the types review is still outstanding, contradicting both the implementation's disclosed open item and the later saved review state. Required fix: reconcile both active documents to the actual current state, remove the impossible self-referential hardcoded scope from a file whose own bytes participate in that scope (refer to the current packet/review ID instead), and rerun the stale-info contradiction check before regenerating packets.
