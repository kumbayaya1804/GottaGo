2. **MAJOR — The reviewer-scope decision uses the working-tree policy, not the policy bytes being committed.** `.claude/hooks/check-review-artifacts.js:241-259` loads `.claude/antigravity-review-policy.json` using `fs.readFileSync`; the changed scope predicate then decides whether Antigravity is optional at lines 832-833. The packet generator independently reads the same working-tree path at `.claude/hooks/review-packets.js:273-284`. If the staged policy says `antigravityScope: all` (or omits the key) while an unstaged working-tree edit says `database`, packet generation omits Antigravity and the gate accepts Codex alone, even though the commit records the broader-review policy. `docs/agent-harness.md:183-205` documents the existing working-tree/index gap, but this change makes that decision-bearing input suppress a required reviewer for high-risk non-database batches. Bind both packet generation and gate evaluation to the staged policy bytes, or fail closed when the policy differs between index and worktree; add a test for that mismatch.

3. **MAJOR — The path rule omits application RPC writers that can change persisted location data.** C7 says the selected paths cover the work Antigravity's overlay is about, but `.claude/hooks/check-review-artifacts.js:143-152` does not match `app/src/features/submit/submitLocation.ts`. That active caller constructs `p_lat`, `p_lng`, accuracy, and location attributes and invokes `supabase.rpc('submit_location', args)` (`app/src/features/submit/submitLocation.ts:22-42`); the server RPC inserts those values into a pending submission (`supabase/migrations/20260731000300_phase5_verify_and_publish.sql:480-544`). A client-only change can therefore alter production location data without touching any current Antigravity path. Other mutating RPC callers, including access-code updates, have the same path-boundary issue. Define how database-writing RPC callers enter the required-review scope, or narrow C7 and the documented claim so it does not imply these data-integrity changes receive Antigravity review.
