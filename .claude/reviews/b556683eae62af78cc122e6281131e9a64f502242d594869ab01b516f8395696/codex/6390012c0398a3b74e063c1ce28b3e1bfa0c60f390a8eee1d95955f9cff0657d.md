### Findings

- [MAJOR] `.claude/hooks/check-review-artifacts.js:543` - `referencesUnsafeFullGateInvocation()` recognizes the literal repo-relative invocation but not semantically equivalent commands that assign the script path to a shell variable or change into the hooks directory first. Executed probes returned `false` for both `SCRIPT=.claude/hooks/check-review-artifacts.js; node "$SCRIPT"` and `cd .claude/hooks && node check-review-artifacts.js`, while returning `true` for the ordinary full invocation. A packet containing either evasion therefore passes this guard yet can direct a blind reviewer to run the full gate, which reads both canonical verdicts and breaks review independence. The new regression test at `.claude/hooks/check-review-artifacts.test.js:507` covers quoting, `node.exe`, encoding, `npx`, and `bash -c`-style visible literals, but not the two demonstrated evasions explicitly called out by this packet. Required fix: define and enforce a fail-closed allowed grammar for executable gate references (fingerprint-only), cover variable assignment/expansion and cwd-relative basename execution, and add real gate tests proving those packet forms are rejected.
- [MAJOR] `.claude/commands/stale-info-scan.md:33` and `docs/stale-info-scan.md:146` - the active stale-scan templates still issue repository-wide `rg` searches over `.claude` without `--glob '!.claude/reviews/**'` and `--glob '!.claude/*-review-latest.md'`. This directly conflicts with the new mandatory blind-review search rule and can expose the other reviewer's current or archived output if the scan is used from a blind review session; one command even searches for the canonical verdict filenames. This batch says an earlier unscoped search already broke blindness, so retaining copy-pasteable unscoped commands in the active workflow is not an acceptable residual. Required fix: add the exclusions to every repository-wide search that can traverse `.claude`, and add a structural regression test covering both active templates (or explicitly prohibit this command during a blind run and provide a blind-safe variant).
