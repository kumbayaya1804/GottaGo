### Findings

1. **BLOCK — the new policy/index binding can accept a different reviewer scope from the one Git records.** `.claude/hooks/check-review-artifacts.js:255-259` treats `git diff --quiet` exit 0 as proof that the working policy equals the index, then `:292` parses the working-tree file. In a disposable Git repository, I committed a regular policy with `antigravityScope: all`, set `git update-index --assume-unchanged` on it, and changed its working-tree value to `database`. `git diff --quiet` exited 0 while `readPolicy()` returned `database`; the index still held `all`. A second fixture staged a symlink as the policy, changed only its target, and obtained the same result (`git diff` exit 0, `readPolicy()` returned `database`, index mode `120000` containing only the link target). Thus `.claude/hooks/review-packets.js:273-293` and the commit gate can both omit Antigravity using policy bytes that the commit does not contain. This directly falsifies C8 and the new assurance in `docs/agent-harness.md:183`. Read and validate the policy blob from the index, or reject nonregular policy entries and compare parsed working bytes against the staged blob independently of Git's stat hints; add both regression cases.

These active lines contradict the newly scoped workflow and C6. Make them conditional on the policy-required reviewer set, including the stale-information scan's missing-packet rule. The latter file is outside the queue, but this batch directly contradicts its active instructions.
