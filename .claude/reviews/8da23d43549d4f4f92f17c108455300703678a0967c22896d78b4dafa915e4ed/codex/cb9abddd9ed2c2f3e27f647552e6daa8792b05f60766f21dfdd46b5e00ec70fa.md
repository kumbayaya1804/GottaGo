In a rollback-scoped call with a real `authenticated` role and JWT subject, `submit_location(chr(8294), ...)` returned a UUID and staged a row whose name bytes were `e281a6`. U+061C and U+2067–U+2069 are further unlisted format-character candidates. Extend the shared rule to cover these invisible-only inputs and add server and form regression cases. Keep ordinary names in all scripts accepted.
