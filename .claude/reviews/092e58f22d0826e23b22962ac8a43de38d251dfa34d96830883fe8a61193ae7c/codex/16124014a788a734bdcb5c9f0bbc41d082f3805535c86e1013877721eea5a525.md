### Evidence Receipts

- [Claude Code hooks reference](https://code.claude.com/docs/en/hooks): exec form spawns `node` directly, substitutes path placeholders within `args`, and requires a real executable on Windows; the unanchored matcher reaches `NotebookEdit`; hook JSON includes `cwd`; `PostToolUse` failure is nonblocking and shows stderr, while `Stop` can block on exit 2. Thus the Node command is a valid dispatch shape, but a failed queue hook is only a notice, not a prevention boundary.
- [Node child-process reference](https://nodejs.org/api/child_process.html): `.cmd`/`.bat` cannot be executed directly without a shell on Windows. The `bd` missing/failing fallback is therefore material; the new Node hooks use `spawnSync` argv rather than shell strings.
- [Git hooks reference](https://git-scm.com/docs/githooks) and [Git pathspec glossary](https://git-scm.com/docs/gitglossary): executable bits matter on POSIX, and literal pathspecs prevent `*`/`?` expansion. They do not preserve a filename after `readQueue()` has trimmed it.
